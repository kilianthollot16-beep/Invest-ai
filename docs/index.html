Marchés : ce qui se passe

Pas de lecture de marché ici. Elle apparaîtra quand le moteur quotidien tournera sur un hébergement gratuit (guide dans le README). Le moteur calcule seulement des indicateurs sur les cours : rendement annualisé, volatilité, baisse maximale, Sharpe, Sortino, corrélations. Il ne lit pas les actualités et n'a pas de données de valorisation (PER, bénéfices).
